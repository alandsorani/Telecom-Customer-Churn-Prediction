# Data source

This project's raw data is **not committed to git** (see rationale below). This file is
the version-controlled record of where it comes from and how to get it — the actual link
between this repository and the external dataset.

| | |
|---|---|
| **Dataset** | Telco Customer Churn |
| **Source** | [kaggle.com/datasets/blastchar/telco-customer-churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) |
| **Original publisher** | IBM (Kaggle mirrors an IBM sample dataset) |
| **Expected file** | `data/raw/WA_Fn-UseC_-Telco-Customer-Churn.csv` |
| **Size / shape** | ~955 KB, 7,043 rows × 21 columns |
| **License** | Kaggle-hosted; redistribution terms unclear — not committed, per project rule in the root `.gitignore` |

The canonical URL above is also a Python constant, `DATASET_SOURCE_URL` in
[`src/config.py`](../src/config.py) — `src/data_cleaning.load_raw()` cites it directly in its
error message if the file is missing, so the source-of-truth link lives in code, not only in
this document.

## How to get it

```bash
kaggle datasets download -d blastchar/telco-customer-churn -p data/raw --unzip
```

(requires a Kaggle account and an API token at `~/.kaggle/kaggle.json`), or download manually
from the link above and place the CSV at the expected path shown in the table.

## Layout

```
data/
├── README.md          # this file — tracked in git
├── raw/                # git-ignored; the untouched Kaggle CSV goes here
└── processed/          # git-ignored; regenerated by the pipeline scripts:
    ├── telco_churn_clean.csv      <- python -m src.data_cleaning
    ├── telco_churn_features.csv   <- python -m src.feature_engineering
    └── telco_churn.db             <- python -m src.build_database
```

Nothing under `raw/` or `processed/` is committed — everything there is either downloaded
(raw) or deterministically regenerated from it (processed). This file, and the code that
reads `DATASET_SOURCE_URL`, are what make that reproducible instead of tribal knowledge.
